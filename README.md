# コラッツ計算機

1以上の整数を入力すると、コラッツ予想の計算プロセスで出現する「奇数」をリアルタイムで抽出し、4進数（および10進数）へと変換して一覧表示するWebアプリケーションです。計算結果の履歴保存・再実行・削除機能を備えています。

🔗 **公開URL**: [https://collatz-nine.vercel.app/](https://collatz-nine.vercel.app/)

---

## 主な機能

- コラッツシーケンス計算 & 4進数変換
  - 入力された初期値（正の整数）から奇数要素のみを抽出し、4進数表記にリアルタイム変換してテーブル表示。
- LocalStorageを活用した履歴管理
  - 計算結果の初期値をブラウザ（`collatz_history`）へ保存。
  - 保存した履歴のワンクリック再実行、および個別削除（`×` ボタン）に対応。
- レスポンシブ & 数学データに最適化したUI
  - PC・スマートフォン問わず画面幅に合わせて表示が自動調整されるカード型レイアウト。
  - 数値テーブルには等幅フォント（Monospace）および数字揃え（`tabular-nums`）を適用し、桁数が伸びても視認性を維持。
